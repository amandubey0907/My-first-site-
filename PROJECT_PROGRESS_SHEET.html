1. Executive Summary & Core Objectives

This module implements a real-time, browser-native Spatial Proximity Sound Engine. It simulates real-world acoustics where sound volume dynamically attenuates with distance according to acoustic decay laws, stereo pans between ears based on relative user angle, and automatically cuts off at boundary distances to save bandwidth and compute resources.

4. Mathematical Acoustic Formulations
1. Haversine Distance (GPS Spherical Geometry):
a = sin²(Δlat / 2) + cos(lat1) · cos(lat2) · sin²(Δlon / 2)
d = 2 · R · atan2(√a, √(1 - a))   [where R = 6,371,000 meters]
2. Inverse Distance Attenuation Curve:
Gain(d) = d_ref / (d_ref + rolloff · (d - d_ref))
Boundary Conditions: If d ≤ d_ref → Gain = 1.0 (Core 100%) | If d ≥ d_max → Gain = 0.0 (Silent Cutoff)
3. Normalized Stereo Panning Bearing:
Pan_factor = clamp((beacon_x - listener_x) / max(0.1, distance), -1.0, +1.0)
